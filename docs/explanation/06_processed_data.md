## 6.3 Deep Dive into 5 Key Derived Columns

### 1. `daily_actual_mm_map` (Sanitized Map Column)
* **What it is:** The official rainfall value used for cartographic rendering and spatial aggregations.
* **Exact Code (`src/rainfall/extremes.py:90–105`):**
  ```python
  def apply_map_column(df: pd.DataFrame, extreme_review: pd.DataFrame) -> pd.DataFrame:
      df["daily_actual_mm_map"] = df["daily_actual_mm"]
      isolated = extreme_review[extreme_review["status"] == "isolated_suspect"]
      for _, r in isolated.iterrows():
          mask = (df["state"] == r["state"]) & (df["district"] == r["district"]) & (df["date"] == r["date"])
          df.loc[mask, "daily_actual_mm_map"] = np.nan
          df.loc[mask, "qc_isolated_extreme"] = True
      return df
  ```
* **Why it matters:** Preserves raw gauge data in `daily_actual_mm` for historical fidelity while setting verified sensor malfunctions (such as Jorhat's unverified 850 mm reading on 2022-07-26) to `NaN` in `daily_actual_mm_map` so maps do not display deceptive anomalies.

### 2. `rain_3d_mm` (Strict 3-Day Rolling Rainfall Sum)
* **What it is:** Total cumulative rainfall recorded over the past 3 consecutive calendar days $[t-2, t-1, t]$.
* **Exact Code (`src/rainfall/hydrology_matrix.py:50–66`):**
  ```python
  # Block slice over NumPy array:
  block = arr[:, w - 2 : w + 1]
  pres = present[:, w - 2 : w + 1]
  ok = pres.all(axis=1) # True only if all 3 days have data
  sums = np.nansum(block, axis=1)
  sums[~ok] = np.nan
  ```
* **Manual Example:**
  * Day 1 (Aug 10): $12.0\text{ mm}$
  * Day 2 (Aug 11): $0.0\text{ mm}$
  * Day 3 (Aug 12): $25.5\text{ mm}$
  * $\text{rain\_3d\_mm} = 12.0 + 0.0 + 25.5 = 37.5\text{ mm}$.
  * *Missing Day Rule:* If Aug 11 was missing (`NaN`), `rain_3d_mm` strictly outputs `NaN` (does NOT assume 0.0 mm).

### 3. `monsoon_cum_mm` (Monsoon Cumulative Total)
* **What it is:** Total cumulative rainfall accumulated since the start of the current year's Southwest Monsoon (June 1st).
* **Reset Condition:** Resets to 0.0 on June 1st of every calendar year. During non-monsoon months (January–May, October–December), it tracks seasonal totals or evaluates complete sequences.

### 4. `dry_spell_len` & `wet_spell_len` (Consecutive Spell Streaks)
* **Definition:**
  * **Rainy Day:** Daily rainfall $\ge 2.5\text{ mm}$.
  * **Dry Day:** Daily rainfall $< 2.5\text{ mm}$.
* **Streak Logic (`src/rainfall/hydrology_matrix.py:95–123`):**
  * If Day $t$ receives $10.0\text{ mm}$ ($\ge 2.5$): `wet_spell_len` increments by 1; `dry_spell_len` resets to 0.
  * If Day $t$ receives $0.0\text{ mm}$ ($< 2.5$): `dry_spell_len` increments by 1; `wet_spell_len` resets to 0.
* **Why it matters:** Critical for agricultural drought monitoring. A district receiving 5 mm of rain every 4 days has no dry spell, whereas a district receiving 0 mm for 25 consecutive days experiences agricultural stress even if total monthly rain is normal.

### 5. `daily_volume_mcm` (Daily Volumetric Water Metric)
* **What it is:** Total volume of water received by the entire district surface area, measured in **Million Cubic Meters (MCM)**.
* **Formula:**
  $$\text{Volume (MCM)} = \text{Rainfall (mm)} \times \text{Area } (km^2) \times 0.001$$
* **Manual Example:**
  * District Area = $5,000\text{ km}^2$.
  * Daily Rainfall = $20.0\text{ mm}$.
  * $\text{Volume} = 20.0 \times 5,000 \times 0.001 = 100\text{ Million Cubic Meters of water}$.
